# Exclusiva Miller | Loja demonstrativa

## Requisitos
- Node.js 20+ recomendado
- Visual Studio Code

## Como executar
1. Extraia o ZIP e abra a pasta `exclusiva_miller` no VS Code.
2. Abra o terminal integrado (Terminal > Novo Terminal).
3. Execute `npm install`.
4. Execute `npm run dev`.
5. Abra no navegador o endereço local exibido pelo Vite.

## Gerar versão de produção
Execute `npm run build`. Os arquivos prontos para hospedagem serão gerados na pasta `dist/`.

## O que já funciona
- Layout responsivo para desktop e celular.
- Vitrine de produtos e filtros por categoria.
- Busca de produtos.
- Modal com detalhes e tamanhos.
- Sacola com adicionar, remover e alterar quantidades.
- Botões demonstrativos para checkout, conta e newsletter.

## Antes de vender de verdade
Este projeto é um front-end demonstrativo. Para aceitar pedidos reais, será necessário integrar backend/API, banco de dados, autenticação, gateway de pagamento, cálculo de frete e serviço de e-mail. Troque o telefone fictício do WhatsApp (`5500000000000`), o e-mail e as imagens pelos dados reais da loja. Preços e produtos são exemplos.
